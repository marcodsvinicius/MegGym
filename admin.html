Conexão com o GitHub

Os exercícios ficam salvos no arquivo data/exercises.json do seu repositório. Para salvar daqui, crie um token pessoal:
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Em Repository access, escolha Only select repositories e selecione este repositório.
  3. Em Permissions → Repository permissions, deixe Contents: Read and write.
  4. Gere, copie e cole abaixo. O token fica salvo só neste navegador.
